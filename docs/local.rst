Texas State Cluster: LEAP2 

.. image:: images/2.png
   :align: center

Texas State University has its own HPC cluster available to Texas State researchers called LEAP2. With 5,808 total CPU cores, 8 NVIDIA A100 GPU nodes, and 100 GB/s, it is a respectable HPC system capable of rigorous scientific workloads. Any student or faculty member can request allocation space through the LEAP2 portal here , though it is also open to requests for external collaborators. Documentation for using the LEAP2 cluster can be found here . It utilizes a SLURM scheduler and is Linux-based. Texas Advanced Computing Center (TACC)

If you are looking for more powerful systems, the Texas Advanced Computing Center, located in Austin, TX also provides allocations for researchers who want to use HPC systems. Home to the fastest academic supercomputer in the U.S ., TACC is a research unit of UT Austin, and it boasts extremely powerful systems: Frontera Compute Nodes: 8,368 nodes CPU: Intel Xeon Platinum 8280 ("Cascade Lake") Cores per Node: 56 cores Total CPU Cores: \~468,000+ Memory per Node: 192 GB DDR4 Interconnect: Mellanox HDR-100 InfiniBand Local Storage: 480 GB SSD/node Lone Star 6 ● Compute Nodes: 560 CPU nodes ● GPU Nodes: 16 accelerator nodes CPU Nodes ● Processor: 2× AMD EPYC 7763 (Milan) ● Cores per Node: 128 cores ● Memory: 256 GB DDR4/node ● Clock Speed: 2.45 GHz GPU Nodes ● GPUs: 2× NVIDIA A100 (40 GB HBM2) per node Stampede3 Other Texan HPC resources Like UT Austin, Texas A&M, UT Dallas, and the University of Houston have HPC clusters of varying size and scale. Although these university-specific clusters are typically only available to students and faculty of the university, they are often accessible through joint research grants, so if you are partnered with one of these institutions, it may be worth examining what resources you have access to.
